# 一、修正方案（已定，按此实现）

## 1.1 键帽只显示非修饰键

面板头部已经有 `Ctrl` 胶囊，每个条目再写一遍 `Ctrl+` 是冗余的。

```
现在： [Ctrl+Backspace] 删除前一个词
改成： [Bksp]           删除前一个词
```

键帽宽度从约 100 px 降到约 50 px，文案多出 50 px ≈ 3 个汉字。

超长键名用缩写：`Backspace→Bksp`、`PageUp→PgUp`、`PageDown→PgDn`、`Delete→Del`、`Insert→Ins`、`PrintScreen→PrtSc`。

**前提**：`HudBuilder` 只输出修饰键完全相等的条目，所以面板内所有条目的修饰键都一样，可以安全省略。

## 1.2 分组改为列内流式

不再「每组从新行开始」，改为按列填充：

```
总格数 = 条目数 + 组名数
每列格数 = ceil(总格数 / 3)
按组顺序依次填入第 1 列，填满转第 2 列
```

效果：组名占一格，紧跟其条目，填满当前列后自然换列。**不会出现「整行只有 1 条」的空白**。

组名格高度与条目一致（26 px），文字 11 px / 55% 白，不额外加组间距。

## 1.3 底色透明度 92% → 96%

规格 §6.1 已更新。判定方式：在浅色高对比背景（白色编辑器 + 黑字）上截图，**背景文字不可辨读**。
