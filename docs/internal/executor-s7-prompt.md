# 角色与本次任务

用户实测提出三件事，本次一起做：

1. **要看到全部**：长按 Alt 要有 F4 及所有 Alt 组合；长按 Ctrl 要有空格、Shift 及所有 Ctrl 组合
2. **装不下就翻页**：**只用 `↑` `↓`**，且翻页键不能误触发前台应用的快捷键
3. **按快捷键老闪菜单**：长按阈值上调

第 1 条改匹配规则，第 2 条引入全项目第一个输入拦截钩子。先看清再动手。

# 二、范围

## 2.1 匹配规则改为「包含」

```csharp
// 旧：Combo.Modifiers == modifier
// 新：Combo.Modifiers.HasFlag(modifier) && VirtualKey != 0
```

- 键帽文字 = 去掉触发修饰键后的部分：`Ctrl+Shift+K` 在 Ctrl 面板显示为 `Shift+K`
- 排序：**修饰键数量少的在前**（`Ctrl+S` 在 `Ctrl+Shift+S` 之前），同数量按原顺序
- 组名沿用档案里的分组

## 2.2 分页

| 项 | 规则 |
|---|---|
| 每页 | 12 条 |
| 页数 | `ceil(总数 / 12)` |
| 翻页键 | **只有 `↑` 和 `↓`** |
| 面板高度 | **固定 12 格**，末页留白，翻页不重建 DIB |
| 页脚（多页） | `第 1/4 页 · ↑↓ 翻页 · 松开 Ctrl 隐藏` |
| 页脚（单页） | `共 8 条 · 松开 Ctrl 隐藏` |
| 边界 | 第一页再按 ↑、末页再按 ↓ → 不动，**不循环** |

## 2.3 翻页键吞噬（本次最高风险）

**只在「总条数 > 12 且面板可见」时**安装 `WH_KEYBOARD_LL`：

```
回调只做一件事：key ∈ {VK_UP, VK_DOWN} && 面板可见 && 有多页 → return 1
其余一律 CallNextHookEx，绝不拦截
```

**单页时完全不装钩子。** 这是用户明确要求的：绝大多数情况下用户根本感觉不到输入被拦截。

**关键设计：钩子只负责吞，不负责翻页。**
翻页逻辑统一由 Raw Input → 状态机驱动，避免两条通路各翻一次。

**必须先验证一个前提**：钩子吞掉后，Raw Input 是否仍收到该键？
- 仍收到（预期）→ 按上述设计，干净
- 收不到 → 改为钩子内 `PostMessage` 发翻页命令，状态机忽略该键的 Raw Input

**这一步要写最小实验确认，不许假设。失败就停下来报告。**

**安全阀（必须做）**：

| 机制 | 值 |
|---|---|
| 面板显示上限 | 15 秒，超时强制收起并卸钩 |
| 收起即卸钩 | `HideRequested` 里同步卸，不延迟 |
| 进程退出 | 卸载钩子（`Dispose`） |

理由：key-up 丢失会让面板一直挂着，钩子就一直吞你的上下键——**这比不能翻页严重得多**。

## 2.4 长按阈值 300 → 450

用户反馈"按快捷键老闪菜单"：300ms 与部分人的按键节奏重叠，面板闪一下就消失。

- `TriggerStateMachine` 构造默认值改 450
- `AppConfig.DwellMs` 默认值改 450
- 范围仍是 80–5000

**测试必须显式传阈值，不许依赖默认值**——现有用例大量用 299/300 断言，默认值一改就会全线飘红。
改成 `new TriggerStateMachine(dwellMs: 300)` 显式指定，另加一条 `Case17 默认阈值为 450`。

## 2.5 数据与熟记名单

**熟记名单收窄**：只保留 Ctrl 单修饰键的高频编辑类（`Ctrl+C/V/X/Z/Y/A/S/F/P/N/O/W/T`）。
移除全部 `Alt+*` 与 `Win+*`——用户明确想看到 `Alt+F4`。

**系统档案**：新增 `Data/apps/_system.json`，`processNames: ["*"]`，≥ 30 条。
应用条目在前，系统条目在后（组名「系统」）。未收录应用时仍显示系统条目。

**档案扩充**（含用户点名的条目）：

| 应用 | 目标 | 必须包含 |
|---|---|---|
| Word | ≥ 20 | `Ctrl+Space`（不间断空格） |
| Chrome | ≥ 20 | `Ctrl+滚轮↑/↓` |
| VS Code | ≥ 25 | `Ctrl+Space`（触发建议） |
| 资源管理器 | ≥ 15 | `Ctrl+滚轮↑/↓` |
| 记事本 | ≥ 10 | — |

> 滚轮模型在上一版 S7 提示词里已定义（伪键 `0x1F00/0x1F01`），本次保留，不重复展开。
> 若上一版尚未实现，本次一并做；已实现则跳过。

# 四、验收用例（10 条）

| # | 项 | 判定 |
|---|---|---|
| 1 | Alt 面板含 Alt+F4 | 按 Alt 能看到 `F4`、`Tab` |
| 2 | Ctrl 面板含 Shift 类 | 能看到 `Shift+K`，键帽不带重复的 Ctrl |
| 3 | Ctrl 面板含空格 | 能看到 `Space` |
| 4 | 分页 | 条目 > 12 时页脚出现 `第 1/N 页`，↓ 翻到第 2 页 |
| 5 | 边界 | 第 1 页按 ↑ 不动；末页按 ↓ 不动，不循环 |
| 6 | **翻页键不误触发** | 面板可见时按 `Ctrl+↓`：面板翻页，**Word 文档光标不动** |
| 7 | 单页不装钩子 | 单页面板可见时按 `Ctrl+↓`，文档光标**正常下移**（说明没拦截） |
| 8 | 翻页不改尺寸 | 翻 3 页，`GetWindowRect` 不变 |
| 9 | 安全阀 | 模拟 key-up 丢失，15 秒后面板自动收起且钩子已卸 |
| 10 | 八项门禁 | 全绿，含新增 `Case17 默认阈值 450` |

**用例 6 和 7 是一对**：6 证明多页时确实拦住了，7 证明单页时确实没拦。只做 6 会做出"永远装钩子"的实现。

# 五、禁止事项

1. 钩子不许拦截 `↑`/`↓` 以外的任何键，包括修饰键本身的 up。
2. 钩子回调里不做 I/O、不分配、不查仓库——只做集合判断。
3. 钩子不许常驻，也不许在单页时安装。
4. 不改 §6.1 的视觉参数（配色、圆角、行高、列数、每页 12 条）。
5. 不把翻页做成循环。
6. 不依赖 `TriggerStateMachine` 的默认阈值写测试。
7. 不凭印象写系统快捷键，每条要有官方文档来源。
