# 角色与本次任务

S7 功能已实现，用户实测发现两类问题：

| # | 现象 | 状态 |
|---|---|---|
| 1 | 豆包 / WorkBuddy / Edge / 网易云 长按 Ctrl 几乎没有内容 | **原因已确认**：这些应用不在档案里，走系统档案，而系统档案纯 Ctrl 条目只有 **1 条** |
| 2 | **Word 里长按 Ctrl 无面板**（推测 PPT 等 Office 应用同样） | **原因未确认**，本次先取证 |

你只负责实现与取证，不负责判断产品方向。**第 2 项在拿到日志前不许改任何逻辑。**

# 一、第一优先：给第 2 项加诊断日志

不要猜。加一条**只在诊断模式下输出**的日志，记录每次 `ShowRequested` 的完整判定链。

## 1.1 日志内容（一行一条，写 `%TEMP%\hotkeyhud-show.log`）

```
[时间] processName=<前台进程名> | profileHit=<true/false> | modifier=<Ctrl> |
total=<N> | pageCount=<N> | suppressed=<true/false> | reason=<抑制原因> |
elapsedSinceArm=<ms> | overlayRect=<l,t,r,b>
```

## 1.2 开关

`--diag` 命令行参数，或 `#if DEBUG` + 环境变量。**Release 不输出**。

## 1.3 纪律

- 日志只写文件，不写控制台（WinExe 无控制台）
- 不改变任何判定逻辑，只观察
- 每条记录必须能区分「没触发」和「触发了但没显示」

# 二、第二优先：按日志判定

在 Word 里复现（按住 Ctrl 至少 1 秒），把 `hotkeyhud-show.log` 最后几行贴进交付说明。

判定表：

| 日志特征 | 结论 | 修法 |
|---|---|---|
| **完全没有新行** | 状态机没触发，或 Raw Input 没收到 | 检查：是否 UIPI（Word 以管理员运行）、是否被抑制、`elapsedSinceArm` 是否 < 阈值 |
| `suppressed=true` | 被游戏/全屏判定误伤 | 看 `reason`，修正对应信号采集 |
| `profileHit=false` | 档案没匹配上 | 检查进程名归一化；Office 可能不是 `WINWORD.EXE` |
| `total=0` | 匹配上了但没有 Ctrl 条目 | 数据问题 |
| `overlayRect` 在屏幕外或尺寸为 0 | 定位/尺寸计算错误 | 检查锚点 |

**把判定结果写进交付说明，再动手改。** 不许跳过这一步直接"我猜是 X"。

# 四、明确不做：Fn 键（写进代码注释与 README）

用户要求支持 `Fn` 快捷键。**这是硬件限制，不是实现问题，本次明确不做。**

## 4.1 为什么做不到

`Fn` 由**键盘固件 / 嵌入式控制器在硬件层处理**，它改变的是键盘上报的扫描码，本身**不产生任何按键事件**。

- Windows 没有 `Fn` 的虚拟键码
- `WH_KEYBOARD_LL` 收不到它
- Raw Input 收不到它
- 微软自家的 PowerToys Keyboard Manager 也明确不支持重映射 Fn

**做了也永远不显示**——面板的触发条件是「检测到修饰键按下」，而 Fn 永远不产生这个信号。加进去就是假功能。

## 4.2 要写进代码与文档的三句话

1. `README` 的「已知限制」加一条：**不支持 Fn**，附上面原因。
2. `GameClassifier`/`Keys` 附近不需要加任何 Fn 相关代码——**不要预留占位**，预留会让人以为将来能填。
3. 若将来有人提这个需求，引用本节的结论，不要重新调研。

## 4.3 不要做的事

- 不要把 Fn 组合写进任何档案 JSON——它们永远不会被匹配到
- 不要试图从扫描码推导 Fn（`Fn+F1` 与 `F1` 在多数键盘上报同一个扫描码，无法区分）
- 不要用"厂商 HID 可能暴露 Fn"来论证可行性——个别键盘有厂商私有用法，但 Windows 不映射为 VK，不可依赖

## 4.4 可替代的（本次也不做）

`Fn` 组合的**实际效果**会以标准媒体键到达：

| 效果 | VK |
|---|---|
| 音量加/减/静音 | `0xAF` / `0xAE` / `0xAD` |
| 播放/暂停 | `0xB3` |
| 上一曲/下一曲 | `0xB1` / `0xB0` |

但这些是**单键**，不符合"长按修饰键触发面板"的模型。要做需要单独设计入口，不在本次范围。
